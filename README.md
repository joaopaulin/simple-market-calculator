# SMC — Calculadora de Mercado Simples (Simple Market Calculator)

Esta é uma calculadora de mercado simples que permite registrar itens durante as compras e acompanhar uma estimativa do valor total antes de chegar ao caixa.

A ferramenta foi pensada para uso rápido no celular enquanto a pessoa percorre o mercado, ajudando a manter controle aproximado do gasto da compra.

## Acessar a aplicação

A calculadora está disponível em:
